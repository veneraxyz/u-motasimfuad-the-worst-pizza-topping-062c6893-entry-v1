# The Worst Pizza Topping

Entry for [The Worst Pizza Topping](https://make.fun/competitions/u-motasimfuad-the-worst-pizza-topping-062c6893) on make.fun.

The program writes one funny line — under 200 characters — pitching the worst pizza topping imaginable: the Wet Gym Sock Pizza, where soggy socks baked onto melted cheese make the first bite taste like a locker room filing for divorce from your mouth.

## Run

```sh
npx tsx main.ts
```

This writes the single entry line to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`).
